# 메디노트 | 의학 학습

의학의 기초 개념과 여러 임상 분야를 강의, 퀴즈, 용어 카드로 공부하는 한국어 학습용 웹앱입니다. 별도 설치나 빌드 과정 없이 브라우저에서 실행할 수 있습니다.

## 시작하기

1. `index.html`을 최신 버전의 Chrome, Edge, Firefox 또는 Safari에서 엽니다.
2. 과목을 선택하고 강의를 읽습니다.
3. 강의별 퀴즈와 용어 카드를 이용해 복습합니다.

인터넷 연결이나 서버는 필요하지 않습니다. 학습 진도와 카드 기록은 현재 브라우저의 `localStorage`에 저장됩니다. 브라우저 데이터나 사이트 저장소를 삭제하면 기록도 사라질 수 있습니다.

## 학습 범위

현재 콘텐츠에는 **22개 과목, 90개 강의, 244개 퀴즈 문항, 302개 핵심 용어**가 포함되어 있습니다.

- **기초 의학:** 해부학, 생리학, 생화학, 병리학, 약리학, 임상 기초
- **기초 과학·임상 추론:** 면역학, 미생물학, 내분비학, 심혈관 의학, 호흡기 의학, 임상 추론과 진단검사
- **전문 분야:** 신경과, 신장내과, 소화기내과, 소아청소년과, 산부인과, 정신건강의학과, 정형외과, 피부과, 안과, 응급의학

각 과목에는 강의가 최소 4개씩 있으며, 과목별 세부 강의 수는 홈 화면에서 확인할 수 있습니다.

## 주요 기능

- **강의:** 주제별 설명, 핵심 용어, 강의별 퀴즈 제공
- **검색 및 과목 필터:** 강의 제목, 용어, 설명을 검색하고 과목별로 강의를 탐색
- **퀴즈:** 문항별 정답 확인과 해설, 결과 및 오답 복습
- **용어 카드:** 알고 있음/모르겠음 응답에 따라 복습 빈도를 조절하는 5단계 학습
- **진도 관리:** 과목별 완료 강의, 퀴즈 최고점, 암기 완료 용어를 브라우저에 저장

## 프로젝트 구조

```text
index.html
css/
  style.css            화면 스타일과 반응형 레이아웃
js/
  app.js               화면 렌더링, 라우팅, 퀴즈, 카드, 진도 관리
  data.js              최초 기초 강의 데이터
  extended-data.js     기초 강의 추가 데이터
  advanced-data.js     기초 과학·임상 과목 데이터
  specialty-data.js    전문 분야 입문 강의 데이터
  expansion-data.js    기존 과목별 확장 강의 데이터
  sparse-data.js       강의 수가 적었던 과목의 보강 데이터
```

강의 데이터는 스크립트 로드 순서에 따라 `MED_DATA`에 추가됩니다. 강의를 수정하거나 추가할 때는 기존 데이터 파일의 과목·강의 구조와 `quiz.answer`의 0부터 시작하는 선택지 인덱스를 따르세요. `index.html`에서 데이터 스크립트가 `app.js`보다 먼저 로드되어야 합니다.
